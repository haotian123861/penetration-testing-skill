渗透测试报告模板


基于 penetration-testing 技能体系构建的专业渗透测试报告模板，内含6个实战案例，覆盖 Critical → Info 五级风险等级。


项目简介


本仓库提供一份开箱即用的渗透测试报告模板，适用于 Web 应用安全评估、内网渗透、代码审计等场景的报告编写。模板严格遵循 OWASP / PTES / NIST 方法论，内置完整漏洞定级体系，帮助安全团队快速产出专业级交付物。
核心特性


五级风险定级体系：Critical / High / Medium / Low / Info，每级含明确定义标准和典型场景
6个实战案例：覆盖未授权访问、SQL注入、反序列化RCE、水平越权、存储型XSS、信息泄露六大高频漏洞类型
完整攻击链：案例之间构成从信息收集→漏洞利用→权限提升→横向渗透的完整风险链路
合规导向：融入《个人信息保护法》合规视角，敏感数据处理声明内置模板
双轨修复建议：短期紧急止血 + 长期根本治理，直接对接业务决策

使用方法
快速开始


复制 Penetration-Test-Report-Template.md 为新文件，命名格式建议：PT-报告-[客户名]-[日期].md
填写封面信息、授权信息等元数据
根据实际测试结果替换漏洞详情章节中的案例内容
补充操作证据、截图和工具输出
导出为 PDF 交付
填写规范


章节	填写要点
执行摘要	控制在1-2页内，管理层只需看这页即可决策
测试范围	授权信息务必完整，这是报告法律效力的基础
漏洞详情	每个漏洞严格按模板结构填写，确保可复现、可验证
操作证据	时间线精确到分钟，确保证据链可追溯
修复建议	必须区分短期止血和长期根治，给出可执行的时间节点
漏洞定级速查


等级	标准	典型场景	整改时限
Critical	可直接获取系统最高权限	RCE、未授权管理员、数据库完全控制	24小时
High	可获取敏感数据或提升权限	SQL注入获取数据、提权、核心逻辑绕过	72小时
Medium	可造成业务影响但需特定条件	存储型XSS、越权访问、敏感信息泄露	2周
Low	信息泄露或轻微影响，利用难度大	反射型XSS、版本泄露、低敏感数据暴露	1个月
Info	情报收集，无直接威胁	服务器版本、HTTP头配置、DNS记录	下次迭代


漏洞详情章节模板结构


每个漏洞独立成节，统一采用以下结构（即4.1~4.7案例的格式）：


plaintext
漏洞标题
├── 基本信息（编号、名称、等级、类型、CVE/CWE、CVSS、影响资产）
├── 漏洞定级依据（五级对照表，勾选匹配项）
├── 漏洞描述（成因、触发条件、攻击目标、业务影响）
├── 复现步骤（逐步命令 + 输出示例）
├── 复现截图（请求包、响应包、执行结果）
├── 影响分析（CIA三要素 + 业务影响，四维评估）
└── 修复建议
    ├── 短期修复（紧急止血，含具体操作命令）
    ├── 长期修复（根本治理，含体系化措施）
    └── 参考链接（官方公告、CVE详情、修复指南）
